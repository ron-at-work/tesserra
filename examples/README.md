# Examples

Examples exercise bounded, current behavior. They are not production deployment recipes and do not expand the implementation status described in the [roadmap](../docs/guides/roadmap.md).

- [Delegated request verification](delegated-request/README.md) — verify the frozen positive two-hop delegation/request evidence.
- [MCP adapter boundary](mcp/README.md) — inspect the scoped MCP proof-propagation helper.
- [SPIFFE adapter boundary](spiffe/README.md) — inspect the workload-identity mapping boundary.
- [A2A adapter boundary](a2a/README.md) — inspect the negotiated A2A extension boundary.

For the runnable local identity/trust walkthrough, use the [quick start](../docs/guides/quick-start.md). For CLI, SDK, and loopback API behavior, use the [API reference](../docs/api/README.md).
