# Roadmap and implementation status

This page describes the current source branch, not a standards endorsement, release-date commitment, or production-support statement. **Implemented** means backed by current source and repository tests. **Partial** means code, fixtures, or a bounded surface exists but its phase gate is not complete. **Planned** means no supported public release should be inferred.

| Phase | Outcome                                                | Status                                                                                                                                                                                                                                                    |
| ----- | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1     | Identity primitives, local trust, offline verification | **Implemented.** Local CLI identity/trust workflow, loopback identity API, SDK verification, encrypted local-key and SQLite foundations, and frozen conformance vectors.                                                                                  |
| 2     | Parent-linked delegation and attenuation               | **Partial.** Deterministic artifact/core/service helpers, SDK verification, conformance cases, local CLI issuance/inspection, and HTTP verification exist. Hosted delegation storage and the phase gate are incomplete.                                   |
| 3     | Signed requests and replay consumption                 | **Partial.** Deterministic helpers, local CLI signing/verification, fixture verification, SDK verification, HTTP verification, and SQLite replay primitives exist. Online exactly-one replay consumption and a complete operator workflow are incomplete. |
| 4     | Revocation and rotation lifecycle                      | **Partial.** Protocol fixtures and storage primitives exist. Default local lifecycle commands fail closed until a distinct status authority, atomic rotation, and end-to-end lifecycle workflow exist.                                                    |
| 5     | Verification events and provenance graph               | **Partial.** A provenance artifact helper/schema and local SQLite graph inspection/export exist. Remote graph, multi-user redaction, and HTTP graph/export routes are not available.                                                                      |
| 6     | MCP proof propagation adapter                          | **Partial.** An adapter helper binds explicit metadata and has tests; it does not replace MCP OAuth or claim arbitrary-client compatibility.                                                                                                              |
| 7     | SPIFFE/SPIRE workload-identity adapter                 | **Partial.** A provider-mapping package consumes validated Workload API material; it does not equate workload identity with an agent, task, or delegation identity.                                                                                       |
| 8     | A2A proof-binding adapter                              | **Partial.** A negotiated-extension helper has tests; it does not implement A2A.                                                                                                                                                                          |
| 9     | Local operations dashboard                             | **Partial.** The separately built typed local-API client has state and accessibility tests. It cannot make unavailable lifecycle or provenance routes available.                                                                                          |
| 10    | Public landing, docs site, and release completion      | **Partial.** Separate landing and docs-site apps, documentation/example checks, benchmark tooling, and a release-artifact workflow exist. No package distribution or supported production release is published.                                           |

Read the [CLI](../api/cli.md), [local API](../api/local-api.md), [SDK](../api/sdk.md), and [adapter boundaries](../adapters/README.md) for current interfaces. The [release guide](../release.md) separates prepared release controls from published artifacts; the [quality/release architecture](../architecture/quality-and-release-architecture.md) and [traceability ledger](../requirements-traceability.md) record phase gates.
