# TESSERRA Milestone 1 implementation-unlock checklist

**Current gate status:** APPROVED FOR IMPLEMENTATION — Phase 1 is unlocked.

This checklist operationalizes the Milestone 1 gate. Plan approval permitted only approved `.md`, `.json`, `.sh`, and `.txt` artifacts under `docs/**` and versioned protocol conformance fixtures in [`tests/conformance/`](../tests/conformance/) with those extensions, plus a dependency-light verifier only at `tests/conformance/self-check.py` or `tests/conformance/v1/self-check.py`; it did not approve implementation. Complete every required item, attach review evidence, and obtain the explicit user sign-off below before creating product code, package manifests, runtime dependencies, migrations, generated SDKs, or application scaffolding.

## Roles and evidence rules

- **Author:** maintains the cited documents and vector corpus.
- **Independent reviewer:** did not create the canonicalization/signature results they reproduce.
- **Security reviewer:** reviews unresolved decisions, controls, and residual risks.
- **Approving user:** provides the final explicit authorization to begin implementation.

Evidence must name a stable repository path and a section, vector ID, command output, or immutable external source. “Reviewed” without an evidence location is incomplete. A failed or intentionally deferred item must remain open and block approval unless the approving user explicitly rejects that requirement through an RFC amendment.

## Review command

Run from the repository root:

```sh
bash docs/review/run-milestone-1-review.sh <approved-base-ref>
```

`<approved-base-ref>` should normally be the commit immediately before Milestone 1 documentation/conformance work. On a repository without commits, run the script without an argument for a working-tree audit. The command relies only on Bash, Git, and standard Unix utilities. It verifies that changed files are confined to `docs/**` or `tests/conformance/**` and checks required artifact paths; it cannot prove citation freshness, semantic completeness, or independent reproduction. Record those human review outcomes above.

## Change control after approval

The approved Milestone 1 evidence revision is `ae22dea` (`docs: define agent proof v1 protocol gate`). [`review/run-milestone-1-review.sh`](review/run-milestone-1-review.sh) archives and verifies that commit by default. After U-12, it validates the frozen documentation/conformance evidence and intentionally does not reject later approved Phase 1 packages, dependencies, tooling, or source files. This preserves the approval evidence while allowing the implementation work it unlocked.

Approval freezes wire bytes, trust semantics, decision precedence, and the declared adapter status. Changes to any of these require an RFC amendment, updated vectors, traceability/threat review, and renewed approval for the affected scope. Future implementation phase gates remain independently blocking.
